# Icônes AZAVISION

Générées à partir de **`LOGO/aza vision logos3.jpeg`** (logo n°3).

| Fichier | Usage |
|---------|--------|
| `favicon-16.png` / `favicon-32.png` | Onglet navigateur |
| `apple-touch-icon.png` | iOS (écran d’accueil) |
| `icon-192.png` / `icon-512.png` | PWA (`site.webmanifest`) |
| `logo-nav.png` | Barre de navigation (hauteur ~44 px) |
| `logo.png` | Pied de page |
| `logo-source.jpeg` | Copie du fichier source |

Les mêmes fichiers sont copiés dans `02-admin-erp/icons/` et `03-google-apps-script/icons/`.

Pour régénérer après changement de logo, remplacer `LOGO/aza vision logos3.jpeg` et relancer le script PowerShell du projet (ou un outil type ImageMagick).
